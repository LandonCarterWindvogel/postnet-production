# Workflow

## Stickers

Incoming → Queued → Printing → Drying → Contour Cutting → Weeding → Quality Check → Ready → Collected

## T-shirt flex

Incoming → Queued → Cutting → Weeding → Heat Press → Quality Check → Ready → Collected

Production can accept an incoming job, return it for correction, and move it through its type-specific workflow. The production board never includes a laminating stage.
